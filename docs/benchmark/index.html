四、方法与局限

  • 对齐：原文与输出逐行做字符级对齐；一处标识符超过一半字符原样保留记为泄漏。标识符与中性值以外被改动的字符记为误改；陷阱在输出中出现次数减少记为丢失。
  • 每个用到模型的配置跑 3 次，取泄漏中位的一次展示，并给出范围；温度 0，但服务端批处理仍有波动。
  • 语料是模板生成的，比真实病历规整、病人跨文件重复（偏向流水线的批内扩散）；没有 OCR 错字、扫描件和超大表格。结果反映各层的作用和短板，不能直接当作真实数据上的泄漏率。
  • “编码字段”模拟区域平台导出：字段名是数据元编码（如 DE02.01.039.00），从名字看不出含义；“裸编号”是不带前缀的纯数字病历号、住院号、门诊号。
